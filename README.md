# 📊 Computational Methods for Data Analysis

**Coursework scripts focusing on the complete data analysis pipeline, from initial data cleaning and transformation to the execution of statistical tests using multiple analytical platforms.**

---

### 💻 Key Analytical Skills

The project is structured around the core stages of quantitative analysis:

| Skill Focus | Description | Implementation Example |
| :--- | :--- | :--- |
| **Data Structure Management** | Creation and manipulation of fundamental structures in R, including **vectors, matrices, factors, and data frames**. | `3.1._Ejercicio_matriz_factores_listas.R`, `4.1._Ejercicio_data_frame.R` |
| **Data Preparation (Wrangling)** | Scripts covering the import, cleaning, and preprocessing of real-world datasets from proprietary formats (`.sav`). | `5.1._Importar_y_limpiar_BBDD.R` |
| **Algorithmic Programming** | Development of custom **functions** and **loops** to automate repetitive data processing and analytical tasks. | `6.1._Funciones.R`, `loop.R` |
| **Statistical Execution** | Application of statistical functions in R and syntax commands in **SPSS** for conducting primary data analyses. | `7.1._Análisis_estadísticos.R`, `SINTAXIS Tarea 2 (MMCCS).sps` |

---

### 🛠️ Technology Stack

* **Primary Language:** R (67.9%)
* **Statistical Environments:** RStudio and IBM SPSS (syntax files).
* **Data Formats:** R scripts and proprietary `.sav` files.
